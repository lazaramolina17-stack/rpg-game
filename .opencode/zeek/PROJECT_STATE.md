# PROJECT STATE

## Proyecto: RPG Game 3D

**Versión:** 0.4.0
**Última actualización:** 2026-07-25
**Estado:** En desarrollo activo

---

## Resumen

RPG de mundo abierto con gráficos 3D procedimentales usando Three.js, construido sobre una base TypeScript con Canvas 2D original. El juego presenta combate en tiempo real, sistema de misiones, habilidades, equipo, crafting, economía y personajes no-jugadores con diálogos.

---
