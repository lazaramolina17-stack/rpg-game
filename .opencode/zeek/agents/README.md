# AGENTS

## Agentes Activos

Los agentes se crean dinámicamente según las necesidades del proyecto.

Ver `system.md` para la lista completa de roles disponibles.

## Estados

- 🟢 Disponible
- 🟡 Trabajando  
- 🔴 Bloqueado
- 🔵 Revisando
- ⚪ Finalizado
- ⚫ Archivado

## Crear un Nuevo Agente

Los agentes se crean automáticamente al delegar tareas mediante `task` tool con el subagent_type apropiado.
